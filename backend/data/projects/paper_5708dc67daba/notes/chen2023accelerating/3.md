# Chen 2023: Accelerating LLM Decoding (Segment 3/8)

## Problem & Method
- Targets speculative sampling acceleration via conditional scoring and modified rejection sampling (algorithmic framework)
- Proposes rejection sampling to recover target model distribution from draft model samples
- Acceptance probability for draft token $x_{\tilde{n}+1}$: $\min\left(1, \frac{q(x_{\tilde{n}+1}|x_1,...,x_n)}{p(x_{\tilde{n}+1}|x_1,...,x_n)}\right)$
- If rejected, resample $x_{n+1} \sim (q(x|x_1,...,x_n) - p(x|x_1,...,x_n))^+$

## Reported Results
- No quantitative results or performance metrics in this segment
- Theoretical analysis of computational components: linear layers, attention mechanism, all-reduces
- Claims scoring should not be significantly slower than sampling for small $K$ if dominant components conditions are met
- Notes other sources of overhead may exist depending on implementation details

## Limitations
- No empirical results reported in this segment
- Overhead sources depend on exact transformer implementation
- Positioning encoding, decoding methods (e.g., nucleus sampling requiring sort), hardware limitations may introduce deltas
