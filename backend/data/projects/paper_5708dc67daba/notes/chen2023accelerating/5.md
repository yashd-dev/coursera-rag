**chen2023accelerating.5** (Pages 6–7)

- **Problem**: Decoding latency bottlenecks in autoregressive LLM sampling; 7B models on 16 TPUs increase latency due to communication overhead.
- **Method**: Speculative sampling with a wider, shallower draft model trained to minimise communication overhead, leveraging robustness to model aspect ratio.
- **Reported results**:
  - HumanEval: near-2.5× speedup (greedy) with parity in benchmark metrics up to numerics.
  - XSum (1-shot): modest speedup; acceptance rate and speedup dependent on domain and decoding method.
  - Theoretical memory bandwidth limit exceeded in HumanEval/greedy XSum.
- **Limits**: Acceptance rate domain-dependent; speedup plateaus/regresses as draft tokens (K) increase; variance increases with K; numerics divergence between ArS and SpS prevents identical outputs.
- **Quote 1**: “We can sidestep this issue by training a wider model with a relatively few number of layers in order to minimise communication overhead.” (Page 6)
- **Quote 2**: “HumanEval achieves a significantly larger speedup — We hypothesize that this is due to a combination of code containing a lot of common sub-sequences… is often decomposed into a smaller set of shorter tokens and the temperature value sharpening both the draft and target logits.” (Page 7)
