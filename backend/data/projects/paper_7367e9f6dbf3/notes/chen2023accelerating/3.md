# chen2023accelerating (3/8)

**Problem**  
- Investigates accelerating LLM decoding via speculative sampling using draft models to generate candidate token continuations.

**Method**  
- Drafts $K$ tokens $\tilde{x}_1, \dots, \tilde{x}_K$ from proposal distribution $q$.  
- For $t=1:K$, samples $r \sim U[0,1]$; accepts $\tilde{x}_{n+t}$ if $r < \min(1, q(\tilde{x}_{n+t}|x_1,\dots,x_n)/p(\tilde{x}_{n+t}|x_1,\dots,x_n))$, else resamples $x_{n+t}$ from $(q(x|x_1,\dots) - p(x|x_1,\dots))_+$ and exits loop.  
- If all $K$ tokens accepted, samples extra token $x_{n+K+1} \sim q(x|x_1,\dots,x_n,\tilde{x}_1,\dots,\tilde{x}_K)$ and increments $n$.  
- Continues while loop iteratively.

**Reported results**  
- No explicit numeric results in this segment; methodology described for recovering target model distribution via modified rejection sampling of drafted tokens.

**Limitations**  
- Overhead sources may depend on transformer implementation, positioning encoding, decoding method (e.g., nucleus sampling sort), and hardware.  
- For small $K$, all-reduce and attention memory bandwidth show little delta between scoring and sampling, but conditions must dominate for scoring not to be significantly slower.
