# Speculative Sampling: Accelerating LLM Decoding

**Problem:** Transformer decoding is memory-bandwidth bound; generating 500B+ parameter models necessitates model parallelism with communication overheads. Each new token depends on the prior, requiring many sequential transformer calls for sequence sampling.

**Method:** Speculative sampling (SpS) introduces a draft model to generate short candidate drafts of length K. These drafts are scored by the target (larger) model using a modified rejection sampling scheme that preserves the target distribution within hardware numerics. When draft and target distributions agree strongly, multiple tokens are accepted per target model call.

**Reported Results:** 
- Benchmarked with Chinchilla (70B parameter model)
- Achieves 2–2.5× decoding speedup in distributed setup
- Mean tokens per second with SpS exceeds the idealized ceiling on auto-regressive sampling speed imposed by memory bandwidth
- No model modifications or distribution biasing required
