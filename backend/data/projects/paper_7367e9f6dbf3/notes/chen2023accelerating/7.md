# Problem
- Significant latency burden during LLM decoding; speculative sampling targets acceleration
- Methods are constrained by verification overhead and draft model quality

# Method
- Speculative decoding employs a draft model to propose multiple tokens, verified by the target model in parallel
- Batch processing of draft tokens amortizes target model inference cost
- Accept/reject logic maintains output distribution fidelity

# Reported results
- Page 9: Speculative sampling yields 2–3× speedup over standard decoding with minimal quality degradation
- Empirical gains scale with draft model size and target model complexity

# Limitations
- Page 9: Verification cost grows with draft token count, limiting parallel efficiency
- Draft model distribution mismatch can introduce acceptance latency or suboptimal token selection
- Requires supplementary training or architecture modifications for optimal performance
