# leviathan2022fast.10

**Problem**  
- Seeks to improve transformer inference efficiency via speculative decoding (page 10)

**Method**  
- Speculative decoding with learned proposal distribution using a lightweight draft model to accelerate generation (page 10)

**Reported Results**  
- 2–3× speedup over baseline with minimal quality degradation across language modeling benchmarks (page 10)  
- Parallel decoding of multiple draft tokens reduces latency without sacrificing correctness (page 10)

**Limitations**  
- Requires training draft model; overhead may not amortize on small requests (page 10)  
- Speed gains diminish with very short generation horizons (page 10)
