# Notes on Leviathan2022Fast (pages 4–5)

- **Problem:** Accelerate inference for transformer-based language models via speculative decoding, reducing expected cost per generated token.

- **Method:** Introduce a smaller "approximation model" Mq to draft tokens; target model Mp validates/drafts via Algorithm 1. Expected cost per token: (cγ+1)(1−α)/T, where γ = number of draft tokens, α = acceptance probability, c = relative cost of Mq.

- **Reported results:**
  - Memory accesses for target weights/KV cache read once per Algorithm 1 execution, shrinking by factor (1−α)/(1−αγ+1) per Eq. (1).
  - Optimal γ maximizes wall-time improvement per Eq. (Theorem 3.8): (1−α)(γc+1); γ is integer, found numerically (Fig. 3).
  - For negligible-cost approximation (c ≈ 0), expected improvement bounded by 1/(1−α), approaching equality as γ grows.
  - n-gram models as Mq: e.g., T5-XXL 11B target with bigram Mq yields α ≈ 0.2, giving 1.25× speedup at γ = 3.

- **Limitations:** Theorem 3.8 assumes long generations; improvement factor capped by number of generated tokens since Mp runs at least once. βs not constant; varying γ per token could yield further gains.

- **Quotes:**
  - "the overall expected cost for producing a token with Algorithm 1 is (cγ+1)(1−α)/T" (p.4, Eq. derivation)
  - "the number of memory accesses for reading them shrinks by a factor of (1−α)/(1−αγ+1)" (p.4, memory access claim)
